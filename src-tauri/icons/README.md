# 应用图标

请在此目录放置应用图标文件：

- `32x32.png` - 32x32 像素图标
- `128x128.png` - 128x128 像素图标
- `128x128@2x.png` - 256x256 像素图标（Retina）
- `icon.icns` - macOS 图标文件
- `icon.ico` - Windows 图标文件

可以使用在线工具生成这些图标，例如：
- https://icon.kitchen/
- https://www.icoconverter.com/

或者使用 Tauri 的图标生成工具：
```bash
yarn tauri icon path/to/your/icon.png
```
