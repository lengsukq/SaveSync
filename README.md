# SaveSync - 通用文件同步工具

一个基于 Electron + React + TypeScript 开发的现代化文件同步工具，支持本地备份和 WebDAV 云端同步。适用于游戏存档、文档、配置文件等任何需要备份和同步的文件。

## ✨ 功能特性

### ✅ 已实现功能

#### 1. 同步项目管理
- 📁 **项目创建和编辑** - 添加、编辑、删除同步项目
- 🎯 **灵活配置** - 自定义项目名称、别名、源路径、描述
- 🔄 **启用/禁用** - 控制项目的同步状态
- 📊 **统计信息** - 显示备份数量（本地/云端/总计）和最后备份时间

#### 2. 备份功能
- 💾 **本地备份** - 手动创建备份，自动压缩为 ZIP 格式
- ☁️ **WebDAV 云端同步** - 支持多个 WebDAV 源配置，自动上传备份到云端
- 📚 **备份历史** - 查看所有备份记录，按项目或类型筛选
- 🔙 **备份恢复** - 从本地或云端恢复备份，恢复前自动备份当前文件
- 🗑️ **备份管理** - 删除本地或云端备份

#### 3. WebDAV 配置
- 🔧 **多源支持** - 配置多个 WebDAV 服务器
- 🏷️ **源命名** - 为每个 WebDAV 源设置名称，方便识别和选择
- 🔐 **安全存储** - 加密存储 WebDAV 凭据
- 📂 **远程路径** - 自定义远程存储路径

#### 4. 用户界面
- 🎨 **现代化设计** - Apple 风格 UI，基于 HeroUI 组件库
- 📱 **响应式布局** - 侧边栏导航，清晰的信息展示
- 🎯 **直观操作** - 卡片式项目展示，便捷的操作菜单
- 🔍 **筛选功能** - 按项目、类型筛选备份

#### 5. 数据管理
- 💾 **本地存储** - JSON 格式存储项目配置和备份元数据
- 🔄 **数据迁移** - 支持旧版本数据格式迁移
- 📁 **跨平台** - 自动适配不同操作系统的数据目录

## 🛠️ 技术栈

- **前端框架**: React 19 + TypeScript
- **UI 组件库**: HeroUI + Tailwind CSS v4
- **状态管理**: Zustand
- **构建工具**: Vite
- **桌面框架**: Electron 30
- **包管理**: Yarn
- **文件压缩**: archiver
- **WebDAV 客户端**: 自定义实现（基于 Node.js http/https）

## 🚀 快速开始

### 1. 安装依赖

```bash
yarn install
```

### 2. 开发模式运行

```bash
yarn e-dev
```

这将启动 Vite 开发服务器和 Electron 应用，支持热重载。

### 3. 构建生产版本

```bash
# 构建前端和 Electron 代码
yarn build

# 构建 macOS 安装包
yarn e-build:mac

# 构建 Windows 安装包
yarn e-build:win
```

### 4. 生成应用图标

```bash
# 安装 sharp 库（如果未安装）
yarn add -D sharp

# 生成图标
yarn generate-icons
```

或使用在线工具转换 `build/icon.svg` 为 `.icns` 和 `.ico` 文件。

## 📖 使用说明

### 创建同步项目

1. 点击"添加同步项目"按钮
2. 填写项目名称和源文件路径
3. 可选：配置 WebDAV 同步（选择已配置的 WebDAV 源或手动输入）
4. 可选：添加项目描述
5. 点击"创建"保存

### 配置 WebDAV

1. 进入"设置"页面
2. 在"WebDAV 配置"标签页添加 WebDAV 源
3. 填写名称、URL、用户名、密码和默认远程路径
4. 保存配置

### 创建备份

- 在项目卡片上点击"立即备份"按钮
- 或通过项目菜单选择"创建备份"
- 备份会自动压缩并上传到配置的 WebDAV（如果已配置）

### 查看备份历史

1. 进入"备份历史"页面
2. 选择要查看的项目
3. 按类型筛选（全部/本地/云端）
4. 可以恢复或删除备份

### 恢复备份

1. 在备份历史中选择要恢复的备份
2. 点击"恢复"按钮
3. 确认恢复操作（系统会自动备份当前文件）

## 🔧 开发指南

### 代码规范

项目遵循 `.cursorrules` 中定义的代码规范：
- 使用 TypeScript 严格模式
- 组件文件不超过 150 行
- 单一职责原则
- 清晰的命名和结构
- 高内聚、低耦合

### 添加新功能

1. 在 `src/types/` 中定义类型
2. 在 `main/ipcHandlers.ts` 中添加 IPC 处理程序
3. 在 `main/preload.ts` 中暴露 API
4. 在 `src/services/` 中添加服务方法
5. 在 `src/components/` 中创建 UI 组件

### 构建和发布

使用 GitHub Actions 工作流进行构建和发布：

1. 在 GitHub 仓库的 Actions 页面
2. 选择 "Build and Release" workflow
3. 点击 "Run workflow"
4. 输入版本号和 Release 说明
5. 等待构建完成，自动创建 Release
